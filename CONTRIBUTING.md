# Участие в gate4.ai

Спасибо, что помогаете. Перед pull request:

1. **Тесты.** `go vet ./... && go test ./...` (в ядре — `./scripts/ci.sh`). Решает код, а не LLM: у политик и правил безопасности — тесты на каждое правило.
2. **Секреты** не попадают в код, журнал, вывод и тесты: в тестах — фейковые сервисы.
3. **SPDX-заголовок** в каждом исходнике (`// SPDX-License-Identifier: …`), лицензия — по репозиторию.

## Лицензии и права на вклад

| Репозитории | Лицензия | Как принимается вклад |
|---|---|---|
| gate4ai, relay, gate4ai-* (коннекторы), e2e | AGPL-3.0-only (в gate4ai — с исключением для коннекторов) | **CLA** (подписывается один раз через CLA Assistant в первом pull request): лицензиар сохраняет право выпускать версии и под другой лицензией |
| sdk-go | Apache-2.0 | **DCO**: `git commit -s` |
| registry | CC0 | DCO |

## Новый коннектор

Репозиторий `gate4ai-<сервис>` на [sdk-go](https://github.com/gate4ai/sdk-go): манифест с минимальными возможностями (`capabilities`), тесты на тестовом хосте, CI по шаблону официальных коннекторов. Для магазина — pull request в [registry](https://github.com/gate4ai/registry) (порядок — в его README). Действия класса `money` проверяются другим коннектором (выписка), а не самим собой.
