# Безопасность

Сообщайте об уязвимостях приватно: через GitHub Security Advisories нужного репозитория («Report a vulnerability») — не в публичных issue.

Особенно важны:
- обход политик, подтверждений или журнала;
- выход коннектора за возможности манифеста (сеть, файлы, браузер, секреты), утечка значения секрета коннектору, агенту, в журнал или вывод;
- подмена пакета или индекса магазина, установка без согласия, обход отзыва;
- доступ к сокету владельца, Web UI или relay без прав.

Мы подтверждаем получение в течение 3 рабочих дней и согласуем с вами срок раскрытия. Отозванные версии коннекторов публикуются в списке `revoked` registry.
